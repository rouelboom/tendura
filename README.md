# Tendura

Telegram-бот для чтения тренировок Training Endurance и отправки отчёта спортсмена.

Команды чтения, утренние уведомления и Алиса показывают также события календаря
и дни отдыха. Сообщения тренера, включая описание выходного, сохраняются в
ответе. Если у дня отдыха нет пояснения, бот сообщает, что тренировок нет.
Оценки и отчёты по-прежнему можно записывать только к тренировкам.

## Локальный запуск

```bash
cp .env.example .env
UV_PROJECT_ENVIRONMENT=.venv uv sync --python 3.13.9 --no-dev
set -a; source .env; set +a
.venv/bin/python -m tendura
```

Нажмите `/` в Telegram, чтобы открыть меню команд. Основные команды:

- `/today`, `/tomorrow`, `/week` — показать тренировки;
- `/feedback` — вручную указать самочувствие и субъективную нагрузку после тренировки;
- `/comment_coros` — подготовить голосовой отчёт последней тренировки COROS к записи в Training Endurance;
- `/comment [текст]`, `/confirm`, `/cancel`, `/edit` — подготовить, подтвердить, отменить или изменить отчёт Training Endurance.

Короткие алиасы: `/t`, `/tm`, `/w`, `/f`, `/cc`, `/c`, `/ok`, `/x`, `/e`. Старый вариант `/comment-coros` также поддерживается, но Telegram не позволяет добавить команду с дефисом в нативное меню.

`/feedback` ищет тренировки текущей календарной недели без полного feedback и не предлагает будущие тренировки. Если подходящих тренировок несколько, бот сначала предлагает выбрать конкретную тренировку; сегодняшняя и вчерашняя показываются первыми. Затем бот показывает все десять уровней самочувствия с названиями и подробными описаниями, а после выбора — такую же шкалу субъективной нагрузки. После выбора обоих значений бот показывает предварительный просмотр. Запись выполняется только после нажатия «Сохранить»; выбор можно начать заново или отменить.

`/comment` предлагает выбрать тренировку за последние семь дней по часовому поясу `TENDURA_TIMEZONE`; кнопка «← Ранее» показывает предыдущую неделю, а если при запуске команды тренировка одна, сразу открывается предварительный просмотр с кнопкой «Другая тренировка». Без текста в команде бот после выбора попросит отправить отчёт обычным сообщением. COROS-команды подставляют в тот же сценарий `Workout Note` с часов и сначала предлагают тренировки на дату активности; кнопка «Другие дни» открывает общий список. Перед записью бот показывает дату, тренировку, источник и текст, предупреждает о перезаписи существующего отчёта и требует `/confirm`; после ошибки сохранения можно повторить `/confirm`. `/edit` ожидает следующее обычное текстовое сообщение и заново показывает предварительный просмотр. `/cancel` или новая подготовка делают старые кнопки неактуальными.

## Секреты

Не добавляйте `.env`, токен Telegram, cookie Training Endurance и `data/coros-oauth.json` в Git. Для cookie используйте полный заголовок `Cookie` успешного запроса Training Endurance, содержащий `ory_kratos_session`. OAuth-файл COROS должен иметь права `600`; его путь задаётся через `TENDURA_COROS_OAUTH_FILE`.

## Развёртывание

Сервис использует `/opt/tendura`, конфигурацию `/etc/tendura/tendura.env`, OAuth-файл `/etc/tendura/coros-oauth.json` с правами `600` и unit-файл `deploy/tendura.service`.
Для доступа бота к Telegram через локальный Xray задайте `TENDURA_TELEGRAM_PROXY=http://127.0.0.1:8080`. Настройка применяется к отправке запросов и получению обновлений Telegram; клиент Training Endurance работает напрямую. Xray запускается отдельным `deploy/xray-tendura.service`, а конфигурация с ключами хранится только на сервере в `/etc/xray/config.json`.

После сетевой ошибки или тайм-аута polling пересоздаёт пул соединений, чтобы
повторный запрос не ждал потерянное соединение в прежнем пуле.
Получение команд Telegram ограничено общим тайм-аутом 45 секунд. Успешные
запросы polling, включая ответы без новых сообщений, уведомляют systemd о
работе бота. Если успешных запросов нет 120 секунд, systemd перезапускает
`tendura.service`. Для этого вместе с кодом нужен актуальный unit-файл
`deploy/tendura.service`; при локальном запуске контроль systemd не действует.

## Приватный навык Алисы

Read-only адаптер Алисы умеет сообщать сегодняшнюю тренировку, календарную
неделю и оставшиеся тренировки от сегодняшнего дня до воскресенья. Официально
гарантированы команды с активационным именем навыка «Тренировочный помощник»;
работа коротких фраз без имени навыка проверяется отдельно на реальной Станции.

Локальная проверка адаптера:

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_alice_*.py' -v
```

Подробные инструкции по приватному навыку, переменным окружения и отзыву доступа
находятся в [`deploy/alice/README.md`](deploy/alice/README.md). Основной вариант
размещения использует существующий сервер Tendura и не требует платёжного
аккаунта Yandex Cloud.
