# Приватный навык Алисы

## Контракт

- Имя навыка: `Тренировочный помощник`.
- Тип: обычный приватный навык Алисы.
- Runtime функции: `python314`.
- Entry point: `alice_function.handler`.
- Backend: Yandex Cloud Function с прямой интеграцией из Яндекс Диалогов.

Интенты и гарантированные команды перечислены в `manifest.json`. Текст каждого файла из `intents/` нужно перенести в одноимённый интент в консоли Яндекс Диалогов.

Навык общего типа гарантированно запускается с активационным именем. Короткие варианты без «спроси у Тренировочного помощника» проверяются отдельно на реальной Станции и не считаются гарантированным контрактом платформы.

## Переменные окружения

- `TENDURA_ALICE_SKILL_ID`;
- `TENDURA_ALLOWED_YANDEX_USER_ID`;
- `TENDURA_TRAINING_ENDURANCE_USER_ID`;
- одна из `TENDURA_TRAINING_ENDURANCE_SESSION` или `TENDURA_TRAINING_ENDURANCE_COOKIE`;
- `TENDURA_TIMEZONE`, по умолчанию `Europe/Moscow`.

Значения не добавляются в Git и не должны попадать в логи функции.

## Сборка и локальная проверка

Из корня репозитория:

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_alice_*.py' -v
deploy/alice/build.sh
unzip -l dist/tendura-alice.zip
```

Архив содержит только точку входа, нужные модули Tendura и `requirements.txt` с
уже используемым `httpx`. Конфигурация, пользовательские данные, Telegram и
COROS в архив не включаются.

## Настройка приватного навыка

1. Создать Cloud Function с runtime Python 3.14, загрузить
   `dist/tendura-alice.zip` и указать entry point `alice_function.handler`.
2. Передать функции перечисленные выше переменные окружения. Не записывать их в
   исходный код или открытые логи.
3. Создать в Яндекс Диалогах обычный приватный навык «Тренировочный помощник» и
   связать его напрямую с функцией.
4. Создать три интента из `manifest.json`, перенеся грамматики из `intents/`.
5. Первый запрос выполнить в тестовой консоли Диалогов, получить
   `session.user.user_id` из запроса и сохранить его как
   `TENDURA_ALLOWED_YANDEX_USER_ID`. Сам идентификатор не публиковать.
6. Проверить гарантированные команды с активационным именем из `manifest.json`.
   Короткие фразы без имени навыка считаются экспериментальными до проверки на
   реальной Станции.

Создание функции, секретов и навыка меняет внешнее состояние, поэтому эти шаги
выполняются только после отдельного согласования.

## Отзыв доступа

Отключить или удалить приватный навык, затем удалить функцию либо очистить её
переменные окружения. Если cookie или session Training Endurance могли стать
доступны третьим лицам, завершить сессию в Training Endurance и заменить секрет
в конфигурации Telegram-сервиса.
