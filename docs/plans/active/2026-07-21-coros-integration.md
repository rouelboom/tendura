## Goal
Получать из COROS завершённые тренировки и извлекать из них текстовый отчёт, продиктованный на часах после тренировки, для показа в Tendura.

## Scope
- Подтвердить, в каком поле COROS хранит продиктованный отчёт, на реальной тестовой тренировке.
- Подключить COROS только через официальный авторизованный способ без хранения пароля или неофициальных cookie.
- Получать список последних активностей и детальные данные конкретной активности.
- Нормализовать идентификатор, дату, тип, длительность, дистанцию и текст отчёта во внутреннюю модель Tendura.
- Показывать найденный отчёт через Telegram без автоматической записи в Training Endurance.
- Синхронизировать идемпотентно и хранить только служебные идентификаторы/время последней обработки.
- Описать выдачу и отзыв доступа, диагностику и ограничения COROS.

## Out of Scope
- Запись тренировок, планов или комментариев обратно в COROS.
- Вход по паролю COROS, перехват браузерной сессии и неофициальные внутренние API.
- Автоматическая запись отчёта из COROS в Training Endurance: это отдельное подтверждаемое действие после приёмки чтения.
- Поддержка нескольких аккаунтов COROS в первом выпуске.

## Context
- Базовая ветка `main` содержит первую рабочую версию Tendura с Telegram long polling и read-only клиентом Training Endurance.
- По официальной справке COROS MCP предоставляет activity records, workout feedback и training notes; именно эти поля нужно сопоставить с отчётом, созданным на часах.
- COROS MCP требует явной авторизации владельца аккаунта и работает с данными только для чтения.
- Классический доступ к COROS API выдаётся по индивидуальной заявке и может быть не одобрен; он является резервным вариантом, а не предпосылкой разработки.
- Связанные модули: `tendura/core`, `tendura/telegram`, `tendura/config.py`, новый изолированный клиент COROS.
- Ограничения: не добавлять секреты в Git, логи и тесты; не отправлять данные COROS в сторонние сервисы; не менять Training Endurance без отдельного подтверждения.
- Источники: [COROS MCP](https://support.coros.com/hc/en-us/articles/50841795180948-COROS-MCP-A-Guide-to-Connecting-Your-Training-Data-to-AI), [заявка на COROS API](https://support.coros.com/hc/en-us/articles/17085887816340-Submit-an-API-Application).

## Decisions
- Первичный путь — официальный COROS MCP с явной авторизацией пользователя, поскольку он документирует чтение activity records, workout feedback и training notes.
- Партнёрский COROS API — резервный путь и требует одобрения COROS; не использовать неофициальные сессии как замену.
- Первая версия интеграции только читает и показывает отчёт; запись в Training Endurance остаётся вне её границ.
- Токены будут храниться только в локальном защищённом файле и `/etc/tendura/tendura.env` с правами `600`.
